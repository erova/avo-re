# Agentic UI Wireframe Kit

**Start prototyping AI-powered interfaces in minutes, not hours.**

This kit contains the design patterns, components, and templates we've learned from building successful agentic tools at avo.re. Use it to quickly spin up new prototypes with consistent, validated patterns.

## Quick Start

**For a new prototype:**
```bash
# 1. Clone or copy this repo
# 2. Open Claude and say:
"I want to build [describe your prototype] using the avo.re wireframe kit.
Read the PROJECT_CONTEXT.md and CLAUDE_INSTRUCTIONS.md files first."

# 3. Claude will help you pick the right template and patterns
```

**To build on someone else's work:**
- Read their PROJECT_CONTEXT.md to understand what they built
- Use Claude to extend it (Claude knows the patterns)
- Add your learnings back to the kit

- **PROJECT_CONTEXT.md** - Overview of the kit, patterns, and principles

## Core Patterns

The kit includes proven patterns for:
- Multi-panel layouts optimized for AI workflows
- Prompt interfaces that avoid the blank canvas problem
- Context visibility (showing what the AI "knows")
- Progress indication and agent transparency
- Iteration and refinement workflows
- Error handling and recovery

## Who Should Use This

- Designers prototyping new agentic features
- Developers building AI-powered interfaces  
- Product managers exploring AI workflow concepts
- Anyone at avo.re creating tools with AI agents

## Philosophy

**Speed through consistency.** These patterns exist because we've validated them in real prototypes. They're not rigid rules—they're starting points that let you move fast while maintaining quality.

**Built for collaboration.** The kit is designed to solve the "AI context handoff problem"—making it easy for teammates to build on each other's AI-generated prototypes.
